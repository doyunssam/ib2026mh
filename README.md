# IB 처음 만나기

IB 연구학교를 처음 접하는 고등학교 교사를 위한 안내 사이트입니다.

- IB 개념·사명·규모와 4개 프로그램(PYP·MYP·DP·CP), 운영 언어
- IB 연구학교 운영 단계(관심 → 후보 → 월드스쿨)와 시도교육청별 현황(대구·제주·서울·대전·부산)
- 고등학교 DP 구조(6개 교과군 + TOK·EE·CAS)
- IB 수업 원리(학습자상, 교수 접근 ATT, 학습 접근 ATL, 핵심 개념·탐구 질문, 백워드 설계)
- 교과별 적용 예시: 국어, 영어, 한국사·역사, 통합사회·사회, 과학, 수학, 정보, 예술·체육
- DP 핵심 과정과 고교학점제·창체 연계, 바로 해 볼 수 있는 체크리스트, FAQ

## GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.

## 수정하기

모든 내용은 `index.html` 한 파일에 들어 있습니다. 교과별 예시는 파일 하단의 `SUBJECTS` 배열에서 고치거나 추가하면 됩니다.
